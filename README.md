# Statistical-Analysis-of-Greenhouse-Gas-Emissions-and-Global-Temperature-Relationships
An analysis of 7 greenhouse gases, 43 countries, and 1990–2014 data from the UN and FAO, using Shapiro-Wilk, Spearman correlation, Kruskal-Wallis, Dunn’s post-hoc test, multivariate regression, Gini coefficients, and GWP analysis.
